# Kardex Support Suite 0.4.21

Release date: 2026-08-02 21:20

## Summary
- Adds a Warehouse Advanced Strategy animated picking comparison view under Reports.
- Shows current picking, aisle/zone module picking and Kardex-assisted picking as separate routes, or all three together in Compare mode.
- Uses six pick points per route so the comparison reflects the same order volume across all strategies.
- Shows Kardex-assisted picking as pick 1-2 at K1, pick 3-4 at K2, then pick 5-6 back at K1 before returning to the start.
- Bundles Shuttle XP and Megamat RS machine images with the suite so installed PCs can show machine visuals without relying on the development asset folder.
- Updates the Warehouse Advanced Strategy presentation with the animated comparison and six-pick route story.
