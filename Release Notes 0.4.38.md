# Kardex Support Suite 0.4.38

Release date: 2026-08-14

## Summary
- Raises customer warehouse render output resolution and exports closer isometric views for sharper zooming.
- Adds Goods Out and Dispatch Area render assets so outbound areas no longer appear as plain blocks.
- Defaults aisles, Kardex machines, conveyors and packing machines to east-west front/rear orientation in renders.
- Reverses the Reception Area front/rear render marker so the visitor entrance side is treated as the front.
- Shows front/rear markers on isometric aisles as well as rendered image assets.
