# Kardex Support Suite 0.4.20

## Summary
- Adds an Exclude Items workflow to Warehouse Advanced Strategy optimisation.
- Allows engineers to enter products, materials, SKUs or item references that must not be included in strategy changes.
- Saves excluded items inside the Advanced Strategy project file.
- Removes excluded items from visible strategy recommendations.
- Applies exclusions to suite-generated Advanced Strategy report rows and Most Picked Items output.
- Applies exclusions to CSV, HTML strategy playbook and Power Pick transfer/change exports where generated through the suite.
- Records excluded items in generated reports so customer-facing outputs clearly show what was deliberately left out.

## Verification
- Built Kardex Support Suite in Release mode with zero warnings and zero errors.
- Confirmed the local Release build opens for user testing before publishing.
